Getting started with Chrome

You can connect Chrome while Downshift downloads its video tools on first
launch. Use the same steps to connect Chrome later from Settings.

1. Open Extensions using the button in Downshift or go to
   chrome://extensions. Turn on Developer mode at the top right.

2. Click Load unpacked.

3. Press Ctrl+V to paste the folder path and press Enter. If Chrome's
   folder picker asks you to confirm, click Select Folder. If you opened
   Extensions yourself, copy this path before pressing Ctrl+V:

   {{EXTENSION_PATH}}

Check that Downshift is switched on and refresh any pages that were already
open. If you already use the same Downshift extension, click Reload on its
extension card. To change extension folders, remove the old copy first.

You are ready. Normal downloads can now be sent to Downshift. For videos,
start playing the video, click Download this video when it appears, choose
the quality (or Default), and click Download Video. Some protected videos
cannot be downloaded, and the button may not appear on every website.

To add a download yourself, open Downshift and click Add download.
For torrents, choose Torrents, then Add torrent.

Closing the main window keeps downloads running in the system tray when
that option is enabled. To stop the app completely, right-click its tray
icon and choose Exit Downshift.

You can reopen these instructions from Start > Downshift > Chrome setup.
